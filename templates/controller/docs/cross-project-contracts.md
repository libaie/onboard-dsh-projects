# Cross-Project Contracts

Frozen agreements between repositories coordinated by this controller.

## How to use

- A contract is frozen BEFORE cross-project dispatch; freeze design and
  contracts, then dispatch.
- Each contract names: the repos involved, the shared interface or behaviour,
  the owner of each side, and the evidence that proves conformance.
- Changes require a new explicit freeze; never edit a frozen contract in
  place silently.
